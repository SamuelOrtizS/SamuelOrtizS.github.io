## 2. Formato de Texto & Estilos Tipográficos

Puedes utilizar **negrita**, *cursiva*, `código en línea`, y [enlaces externos](https://docs.astro.build) dentro de tus párrafos.

> "El código es como el humor. Cuando tienes que explicarlo, es malo." — Cory House

### Listas Desordenadas & Ordenadas

- **Sistemas Embebidos**: Microcontroladores ESP32, STM32 y C/C++.
- **Telecomunicaciones**: Procesamiento de señales, antenas y modulación.
- **Desarrollo Web**:
  - Astro (Static-First Output)
  - Next.js / React
  - Tailwind CSS v4

1. Inicializar el entorno con `npm run dev`.
2. Crear un nuevo archivo `.md` o `.mdx` en `src/content/blog/`.
3. Validar los cambios localmente en el navegador.

## 3. Bloques de Código con Resaltado Sintáctico

```typescript
// Ejemplo de interfaz tipada en TypeScript
export interface EngineeringProfile {
  name: string;
  university: string;
  focus: string[];
  isIEEEActive: boolean;
}

export function getStatus(profile: EngineeringProfile): string {
  return `${profile.name} - ${profile.university} (${profile.focus.join(', ')})`;
}
```
