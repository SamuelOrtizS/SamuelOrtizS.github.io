# Hola Mundo en MDX

Este es un ejemplo de **contenido MDX** en Astro. MDX te permite mezclar componentes React dentro de tu documentación.

## Características de MDX

- ✅ Soporte para componentes React
- ✅ Markdown estándar + JSX
- ✅ Perfecto para documentación y blogs

---

# Usando Componentes

Aquí hay un ejemplo con un componente simulado:

```jsx
const MyComponent = () => (
  <div className="card">
    <h2>Título del Componente</h2>
    <p>Este es contenido de React dentro de MDX.</p>
  </div>
);
```

Puedes importar componentes en tus archivos `.mdx`:

```js
import MyComponent from '../components/MyComponent.astro';

# Mi Contenido

<MyComponent />
```
